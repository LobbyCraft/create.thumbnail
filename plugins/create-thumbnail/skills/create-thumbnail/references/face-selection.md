# Roblox face selection

The catalogue lists classic face IDs recorded under Roblox's official creator account. For an entry, open `https://www.roblox.com/catalog/<asset_id>`. If verification matters, check the listing or the official metadata at `https://economy.roblox.com/v2/assets/<asset_id>/details` for creator ID 1 and asset type 18. Source availability can change.

If the user provides a face texture, use it as the image reference. Apply a complete face at a proportionate scale. A smug expression can convey advantage, crying can convey disadvantage, and distinct knocked-out and death expressions can communicate different game states. Use a supplied face for an exact user-specific override. For exact placement and fidelity, inspect the result against the texture.
