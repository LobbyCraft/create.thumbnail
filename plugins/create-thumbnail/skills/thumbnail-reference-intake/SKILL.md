# Thumbnail reference intake

Inspect the actual supplied images. If missing, ask the user to attach them; do not invent their contents. Separate style examples from exact avatars, game assets and scene requirements. Ask only when their intended role is ambiguous.

For each reference record its stable filename or available persistent identifier, format, subject hierarchy, Roblox avatar proportions, facial expression, camera, lighting, colour palette, background density, text treatment and transferable traits. Never assert CTR performance from appearance alone. Note conflicts with current instructions and resolve using the user's direction.

Summarise a concise proposed style profile, retaining distinct styles as named alternatives when useful. Use those references immediately for the current task if requested. Do not require confirmation merely to analyse references or generate an already requested image.

Return a reusable style brief if the user wants to reuse the findings across chats. Include source links and separate observed visual traits from performance claims. Use the brief with the user's reference attachments in a later session.
